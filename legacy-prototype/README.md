# Arogya — Patient Case-Taking Software

SIH 2026 prototype aligned to problem statement SIH26047.

## What this prototype demonstrates
- Patient registration
- Guided clinical history capture
- Optional demo voice-input flow
- AI-assisted information structuring and summary
- Doctor review/edit workflow
- Case records dashboard
- Recent activity/audit-style timeline
- Responsive UI
- Prototype privacy/clinical-control messaging

## Run
No build step is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best results, use Chrome/Edge.

## Important
This is a front-end demonstration using synthetic/demo data. It does not provide diagnosis or medical advice. A production version would require secure authentication, encryption, audit logging, validated clinical workflows, privacy/compliance controls, persistent storage, and approved AI services.
